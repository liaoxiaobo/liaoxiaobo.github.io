# 内置工具总览

这是 Claude Code 工具参考文档的内容总结：

---

## 🧰 工具总览

Claude Code 内置了一套工具，帮助它理解和修改代码库。工具名称是你在权限规则、子代理工具列表和钩子匹配器中使用的确切字符串。如果想完全禁用某个工具，可以将其名称加入权限设置的 `deny` 数组中。

---

## 📋 所有内置工具一览

按功能分类整理：

**文件读写**

- `Read` — 读取文件内容（无需权限）

- `Write` — 创建或覆盖文件（需权限）

- `Edit` — 对指定文件做精准编辑（需权限）

- `NotebookEdit` — 修改 Jupyter notebook 单元格（需权限）

**搜索与导航**

- `Glob` — 按类型匹配查找文件（无需权限）

- `Grep` — 在文件内容中搜索模式（无需权限）

- `LSP` — 代码智能：跳转定义、查找引用、类型错误提示（无需权限）

**命令执行**

- `Bash` — 执行 Shell 命令（需权限）

- `PowerShell` — Windows 下执行 PowerShell 命令，需手动开启（需权限）

**网络**

- `WebFetch` — 抓取指定 URL 的内容（需权限）

- `WebSearch` — 执行网络搜索（需权限）

**任务管理**

- `TaskCreate / TaskGet / TaskList / TaskUpdate / TaskStop` — 任务列表的增删改查

- `TodoWrite` — 非交互模式下管理任务清单

**代理与编排**

- `Agent` — 生成子代理，拥有独立上下文（无需权限）

- `AskUserQuestion` — 向用户提多选问题（无需权限）

- `Skill` — 执行技能工作流（需权限）

- `EnterPlanMode / ExitPlanMode` — 进入/退出计划模式

- `EnterWorktree / ExitWorktree` — 进入/退出 git worktree 隔离环境

- `SendMessage` — 向 Agent 团队成员发消息（实验性功能）

- `TeamCreate / TeamDelete` — 创建/解散 Agent 团队（实验性功能）

**定时任务**

- `CronCreate / CronDelete / CronList` — 在会话内创建/删除/查看定时任务

**MCP 相关**

- `ListMcpResourcesTool` — 列出 MCP 服务器暴露的资源

- `ReadMcpResourceTool` — 读取指定 MCP 资源

- `ToolSearch` — 搜索并加载延迟工具

---

## ⚙️ 几个重要行为说明

**Bash 工具：** 工作目录在命令间持久保留，但环境变量不会持久。在一条命令中 `export` 的变量，下一条命令中不可用。建议在启动 Claude Code 前先激活虚拟环境。

**LSP 工具：** 每次文件编辑后，LSP 工具会自动报告类型错误和警告，让 Claude 无需单独构建步骤就能修复问题。它还支持跳转定义、查找引用、获取类型信息、列出文件符号、查找接口实现、追踪调用层级等操作。需要安装对应语言的代码智能插件才能激活。

**PowerShell 工具（Windows）：** 这是一个需要手动开启的预览功能，通过设置 `CLAUDE_CODE_USE_POWERSHELL_TOOL=1` 启用。目前已知限制包括：不支持 Auto 模式、不加载 PowerShell 配置文件、不支持沙箱、仅支持原生 Windows（不支持 WSL），且启动 Claude Code 仍需要 Git Bash。
